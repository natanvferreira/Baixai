Baixaí

Baixe vários vídeos do YouTube de uma vez. Cole os links, escolha a pasta e clique em Baixar.

Baixar para Windows Ver o código

Grátis, sem anúncios e sem instalação. É só um .exe.

O que ele faz

Vários de uma vezUm link por linha, quantos você quiser.
Só o áudioSalva em MP3 com um clique.
Playlists inteirasCole o link da playlist e pronto.
Avisa atualizaçãoMostra um botão quando sai versão nova.

Como usar

  1. Baixe o Baixai.exe e dê dois cliques.
  2. Se o Windows avisar "O Windows protegeu o computador", clique em Mais informações → Executar assim mesmo. O aviso aparece porque o programa não é assinado.
  3. Cole os links, escolha a pasta e clique em Baixar.
